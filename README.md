# Proyecto-Multitema
-ForoMultitematico
-El Objetivo es básicamente crear un foro en el que se pueda aportar ideas o ayudas a otros usuarios de diversos temas 
-se pretende un diseño mas original utilizando frameworks como Bootstrap 5.3.8 o superior 
-se Pretende Aplicar conocimientos Adquiridos tanto en Backend Como Frontend
-Para el Backend se Utiliza Laravel 12 o la versión más reciente a la fecha para gestionar la logica del foro
-Los datos de los usuarios y del foro como chats o conversaciones se Guardaran MYSQL pero si se ven Limitaciones quizás se cambie de Motor de Gestor de Base De datos
